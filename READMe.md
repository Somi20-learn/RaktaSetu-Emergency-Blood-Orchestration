# RaktaSetu 🩸
### Real-Time Emergency Blood Matching Platform

RaktaSetu is a platform designed to help hospitals find compatible and available blood sources during emergency situations. It connects hospitals, blood banks and eligible donors in one place.

## Problem

During emergencies, finding the required blood group can take a lot of time. Hospitals may have to contact different blood banks or search for donors separately.

## Our Solution

RaktaSetu helps hospitals create a blood request and find suitable available sources based on:

- Blood group compatibility
- Blood availability
- Distance from the hospital
- Emergency priority
- Donor eligibility
- Blood unit expiry date

The system gives priority to available blood units with the nearest expiry date so that usable blood is not wasted.

## Main Features

- Create emergency blood requests
- Check blood group compatibility
- Find nearby blood banks and eligible donors
- Prioritize urgent requests
- Give priority to units nearing expiry
- Reserve a blood unit for a request
- Track the request status
- Escalate the request if no suitable source is found

## Technology We Plan to Use

- Frontend: React
- Backend: Node.js and Express.js
- Database: MongoDB
- Maps: Leaflet and OpenStreetMap
